# Online Check-in Prototype UI

React/pnpm workspace prototype adapted for Virgin Australia online check-in, with a VDS design-system package structure, design tokens and reusable UI library.

## Runtime

Use Node.js 20.19 or newer. Vite/Vitest use native optional bindings that should be installed with the same runtime used for builds and tests.

## Scripts

- `pnpm install`
- `pnpm dev` starts the UI on `http://127.0.0.1:7001`
- `pnpm build` builds design-system packages and the check-in app
